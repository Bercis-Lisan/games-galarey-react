# 🎮 Games Gallery App

A modern and responsive **Games Gallery App** built with **React** that showcases a collection of **12 game logos** in a clean and interactive interface. This project demonstrates React fundamentals, reusable components, and responsive UI design.

## 🚀 Features

* 🎮 Displays 12 game logos
* ⚛️ Built using React
* 📱 Fully responsive design
* 🧩 Reusable React components
* 🎨 Clean and modern user interface
* ⚡ Fast and smooth performance

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/games-gallery-app.git
```

2. Navigate to the project folder

```bash
cd games-gallery-app
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```

The app will run at:

```text
http://localhost:3000
```
